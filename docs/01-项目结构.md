# 项目结构

本站使用自研主题（无第三方主题），所有模板和样式都在仓库根目录的 `layouts/` 和 `assets/` 中。

```
omnifj.github.io/
├── .github/
│   └── workflows/
│       └── hugo.yaml        # GitHub Actions 自动部署工作流
├── archetypes/
│   └── default.md           # 新建文章时的 frontmatter 模板
├── assets/                  # Hugo 管道处理的资源（压缩 + 指纹）
│   ├── css/
│   │   ├── base.css         # 设计变量、导航、页脚、按钮、返回顶部
│   │   ├── home.css         # 首页：hero、主题条、精选、文章行
│   │   ├── post.css         # 文章页：正文排版、代码高亮、TOC
│   │   └── pages.css        # 分类/归档/关于/友链/搜索/作品/404
│   └── js/
│       ├── main.js          # 进度条、导航滚动、移动端菜单、返回顶部
│       └── search.js        # 搜索页前端检索逻辑
├── content/                 # 所有内容（Markdown）
│   ├── posts/               # 博客文章
│   ├── about.md             # 关于页（layout: about）
│   ├── archives.md          # 归档页（layout: archives）
│   ├── friends.md           # 友链页（layout: friends）
│   ├── search.md            # 搜索页（layout: search）
│   └── works.md             # 作品页（layout: works）
├── data/
│   ├── friends.json         # 友链数据
│   └── works.json           # 作品数据
├── layouts/
│   ├── _default/
│   │   ├── baseof.html      # 全站骨架（head/导航/页脚/JS）
│   │   ├── single.html      # 文章页
│   │   ├── list.html        # section 列表页（如 /posts/）
│   │   ├── terms.html       # 分类/标签总览页（/categories/、/tags/）
│   │   ├── term.html        # 单个分类/标签页
│   │   ├── archives.html    # 归档页（按年分组）
│   │   ├── about.html       # 关于页（卡片网格）
│   │   ├── friends.html     # 友链页
│   │   ├── search.html      # 搜索页
│   │   └── works.html       # 作品页
│   ├── partials/
│   │   ├── head.html        # <head>：SEO 元数据、CSS 合并压缩
│   │   ├── site-header.html # 顶部导航
│   │   ├── site-footer.html # 页脚
│   │   └── post-row.html    # 文章行组件（首页/列表/搜索复用）
│   ├── index.html           # 首页
│   ├── index.json           # 首页 JSON 输出，搜索索引
│   ├── 404.html             # 404 页
│   └── robots.txt           # robots.txt 模板
├── static/                  # 原样拷贝到站点根目录（favicon、验证文件等）
├── docs/                    # 项目文档（本目录，不参与构建）
├── public/                  # Hugo 构建输出目录（已 gitignore，勿手动修改）
├── resources/_gen/          # Hugo 资源缓存（已 gitignore）
├── hugo.toml                # 站点主配置
├── .gitattributes           # 统一 LF 换行
└── .gitignore
```

## 关键目录说明

| 目录/文件 | 作用 | 是否提交 git |
|---|---|---|
| `content/` | 写作主目录，所有 Markdown 文章 | 是 |
| `hugo.toml` | 站点标题、菜单、参数配置 | 是 |
| `layouts/` | 自研主题的全部模板 | 是 |
| `assets/` | CSS/JS，经 Hugo 管道合并、压缩、加指纹 | 是 |
| `data/` | 友链、作品等结构化数据 | 是 |
| `static/` | 文件原样复制到站点根路径 | 是 |
| `public/` | 构建产物，部署的就是它 | 否 |
| `resources/_gen/` | 资源处理缓存 | 否 |
| `.github/workflows/hugo.yaml` | push 到 main 后自动构建并部署到 Pages | 是 |

## 修改主题的注意事项

主题即本仓库，直接修改对应文件即可：

- 页面结构：改 `layouts/` 下对应模板
- 样式：改 `assets/css/` 下对应 CSS 文件（按页面拆分）
- 交互：改 `assets/js/`（`main.js` 全站加载，`search.js` 仅搜索页）
- CSS/JS 修改后 Hugo 会自动重新生成指纹文件名，无需担心缓存
