# 项目结构

```
omnifj.github.io/
├── .github/
│   └── workflows/
│       └── hugo.yaml        # GitHub Actions 自动部署工作流
├── archetypes/
│   └── default.md           # 新建文章时的 frontmatter 模板
├── assets/                  # 需要 Hugo 管道处理的资源（CSS/JS/图片）
├── content/                 # 所有文章内容（Markdown）
│   ├── posts/               # 博客文章
│   │   └── hello-world.md
│   └── about.md             # 关于页
├── data/                    # 数据文件（JSON/YAML/TOML），供模板调用
├── layouts/                 # 自定义模板，优先级高于主题同名文件
├── static/                  # 原样拷贝到站点根目录的文件（如 CNAME、favicon）
├── themes/
│   └── PaperMod/            # PaperMod 主题（git submodule，勿直接修改）
├── docs/                    # 项目文档（本目录，不参与构建）
├── public/                  # Hugo 构建输出目录（已 gitignore，勿手动修改）
├── resources/_gen/          # Hugo 生成的缓存资源（已 gitignore）
├── hugo.toml                # 站点主配置文件
├── .gitignore
├── .gitmodules              # 主题 submodule 配置
└── README.md
```

## 关键目录说明

| 目录/文件 | 作用 | 是否提交 git |
|---|---|---|
| `content/` | 写作主目录，所有 Markdown 文章 | 是 |
| `hugo.toml` | 站点标题、主题、菜单、参数配置 | 是 |
| `themes/PaperMod` | 主题，通过 submodule 关联上游仓库 | 是（submodule 引用） |
| `static/` | 文件原样复制到站点根路径，如 `static/robots.txt` → `/robots.txt` | 是 |
| `layouts/` | 覆盖主题模板的自定义页面 | 是 |
| `assets/` | 需要压缩/处理的资源，通过模板引用 | 是 |
| `public/` | 构建产物，部署的就是它 | 否 |
| `resources/_gen/` | 图片/CSS 处理缓存 | 否 |
| `.github/workflows/hugo.yaml` | push 到 main 后自动构建并部署到 Pages | 是 |

## 修改主题的注意事项

不要直接改 `themes/PaperMod/` 里的文件（submodule 更新会丢失修改）。正确方式：

- 覆盖模板：把要改的模板复制到 `layouts/` 对应路径再修改
- 自定义 CSS：在 `assets/css/extended/` 下新建 `.css` 文件，PaperMod 会自动加载
