# 发布流程

## 触发方式

推送到 `main` 分支即自动触发构建部署，无需其他操作：

```bash
git add -A
git commit -m "new post: xxx"
git push
```

也可手动触发：GitHub 仓库 → Actions → Deploy Hugo site to Pages → Run workflow。

## 部署原理

工作流文件：`.github/workflows/hugo.yaml`，分两个 job：

1. **build**
   - 检出代码（含 PaperMod submodule）
   - 安装 Hugo extended 0.167.0
   - 执行 `hugo --minify` 构建到 `public/`
   - 上传 `public/` 为 Pages artifact
2. **deploy**：将 artifact 发布到 GitHub Pages

整个过程约 1 分钟。

## 查看部署状态

- 打开 https://github.com/omnifj/omnifj.github.io/actions
- 绿色勾 = 成功，红色叉 = 失败（点进去看日志）
- 成功后访问 https://omnifj.github.io/ 验证

注意：GitHub Pages 有 CDN 缓存，部署成功后个别页面可能延迟 1~2 分钟更新。

## 常用命令速查

```bash
# 本地预览（含草稿）
hugo server -D

# 本地完整构建（验证是否有报错）
hugo --minify

# 更新 PaperMod 主题到最新版
git submodule update --remote themes/PaperMod
git add themes/PaperMod
git commit -m "update PaperMod theme"
git push

# 回滚到上一次部署
git revert HEAD
git push
```
