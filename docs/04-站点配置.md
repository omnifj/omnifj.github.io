# 站点配置

主配置文件：`hugo.toml`。修改后 push 即可生效。

## 当前配置说明

```toml
baseURL = "https://omnifj.github.io/"   # 站点根 URL，绑域名后改为域名
locale = "zh-cn"
title = "omnifj's Blog"                 # 站点标题
theme = "PaperMod"
enableRobotsTXT = true                  # 允许搜索引擎抓取
```

## [params] 功能开关

| 参数 | 当前值 | 作用 |
|---|---|---|
| `defaultTheme` | `auto` | 跟随系统明暗主题，可改 `light` / `dark` |
| `ShowReadingTime` | `true` | 显示阅读时长 |
| `ShowShareButtons` | `true` | 文章底部分享按钮 |
| `ShowPostNavLinks` | `true` | 上一篇/下一篇导航 |
| `ShowBreadCrumbs` | `true` | 面包屑导航 |
| `ShowCodeCopyButtons` | `true` | 代码块复制按钮 |
| `ShowToc` | `true` | 文章目录 |
| `TocOpen` | `false` | 目录默认折叠 |

## 首页欢迎语

```toml
[params.homeInfoParams]
  Title = "欢迎来到我的博客"
  Content = "这里记录技术、阅读与生活。"
```

## 导航菜单

`[menu.main]` 下的每一项对应顶部导航，`weight` 决定顺序。添加新页面（如归档）：

```toml
[[menu.main]]
  identifier = "archives"
  name = "归档"
  url = "/archives/"
  weight = 25
```

同时创建 `content/archives.md`：

```markdown
---
title: "归档"
layout: "archives"
url: "/archives/"
---
```

## 绑定自定义域名

1. 创建 `static/CNAME`，内容为域名（如 `omnifj.com`）
2. `hugo.toml` 的 `baseURL` 改为 `https://omnifj.com/`
3. GitHub 仓库 Settings → Pages → Custom domain 填入域名
4. 配置 DNS：根域名加 4 条 A 记录指向 `185.199.108~111.153`；子域名加 CNAME 指向 `omnifj.github.io`
5. push 后等待 SSL 证书自动签发

更多参数见 PaperMod Wiki：https://github.com/adityatelange/hugo-PaperMod/wiki
