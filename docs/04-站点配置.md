# 站点配置

主配置文件：`hugo.toml`。修改后 push 即可生效。本站使用自研主题（模板在 `layouts/`，样式在 `assets/css/`），无 `theme` 配置项。

## 当前配置说明

```toml
baseURL = "https://omnifj.github.io/"   # 站点根 URL，绑域名后改为域名
title = "omnifj"                        # 站点标题（导航、页脚、<title> 使用）
locale = "zh-CN"
defaultContentLanguage = "zh"
enableRobotsTXT = true                  # 允许搜索引擎抓取
enableGitInfo = true                    # 用 git 提交时间作为文章更新时间
paginate = 8                            # 每页文章数（分页列表预留）
```

## [params] 参数

| 参数 | 当前值 | 作用 |
|---|---|---|
| `description` | 记录技术、阅读与生活 | 站点简介：首页 lede、页脚、meta description |
| `author` | omnifj | 作者名：导航角标、页脚版权、JSON-LD |
| `keywords` | [...] | 站点级关键词（meta keywords / JSON-LD） |
| `since` | 2026 | 首页 hero 的「SINCE」年份 |
| `github` | https://github.com/omnifj | 导航/页脚的 GitHub 链接、作品页入口 |
| `email` | omnivue666@gmail.com | 关于页联系链接 |
| `heroLine1` / `heroLine2` | omni / fj。 | 首页大标题两行文案 |

## 导航菜单

菜单配置在 `[[menu.main]]`，`weight` 决定顺序。当前包含：文章/分类/作品/归档/链接/搜索/关于。当前页菜单项会自动高亮。

新增页面步骤：

1. 创建 `content/xxx.md`
2. 如需特殊版式，在 frontmatter 指定 `layout: xxx`，并在 `layouts/_default/xxx.html` 创建模板
3. 在 `[[menu.main]]` 添加菜单项

## 首页输出格式

```toml
[outputs]
  home = ["HTML", "RSS", "JSON"]
```

JSON 输出由 `layouts/index.json` 生成，是搜索页（`/search/`）的数据源，不要移除。

## 代码高亮

```toml
[markup.highlight]
  style = "monokai"
```

实际配色由 `assets/css/post.css` 中的 `.highlight` 规则控制（Chroma 短类名），改样式改 CSS 即可。

## 绑定自定义域名

1. 创建 `static/CNAME`，内容为域名（如 `blog.example.com`）
2. `hugo.toml` 的 `baseURL` 改为 `https://blog.example.com/`
3. GitHub 仓库 Settings → Pages → Custom domain 填入域名
4. 配置 DNS：根域名加 4 条 A 记录指向 `185.199.108~111.153`；子域名加 CNAME 指向 `omnifj.github.io`
5. push 后等待 SSL 证书自动签发
