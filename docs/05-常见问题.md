# 常见问题

## 文章不显示

- 检查 frontmatter 中 `draft` 是否为 `false`
- 检查 `date` 是否是未来时间（未来日期的文章默认不发布）
- 本地用 `hugo server -D` 能看到、线上没有 → 就是 draft 或日期问题

## 改了 CSS/JS 但本地没生效

Hugo 资源缓存未更新，清理后重启：

```bash
hugo --gc
hugo server -D
```

浏览器也记得强制刷新（Ctrl+F5），主题已对 CSS/JS 文件加内容指纹，线上无此问题。

## 搜索页无结果或提示索引加载失败

- 确认 `hugo.toml` 中 `[outputs] home` 包含 `"JSON"`
- 确认 `layouts/index.json` 存在
- 本地构建后检查 `public/index.json` 是否生成、内容是否为文章数组

## Actions 构建失败

先到 Actions 页面看日志，常见原因：

- Markdown frontmatter 语法错误（如引号未闭合）→ 本地跑 `hugo --minify` 能复现
- 模板语法错误 → 同样本地可复现，先本地构建通过再 push

## Actions 失败：权限不足

仓库 Settings → Actions → General → Workflow permissions 设为 **Read and write permissions**。

## 部署成功但页面样式丢失/404

通常是 `baseURL` 与实际访问地址不一致：

- 用户主页仓库：`baseURL = "https://omnifj.github.io/"`
- 项目页仓库：必须带仓库名，如 `https://omnifj.github.io/my-blog/`

## 本地构建报错 SCSS not supported

Hugo 不是 extended 版本。`hugo version` 输出必须包含 `extended`。Windows 安装：

```powershell
winget install Hugo.Hugo.Extended
```

## git 推送/克隆失败：Connection was reset

本机需要代理访问 GitHub。当前 git 已配置：

```
http.proxy = http://127.0.0.1:7897
http.sslBackend = openssl
```

如果代理软件更换端口，同步更新：

```bash
git config --global http.proxy http://127.0.0.1:<新端口>
git config --global https.proxy http://127.0.0.1:<新端口>
```

不需要代理时可取消：`git config --global --unset http.proxy`

## 网站显示的是旧的 Jekyll/README 页面

说明 Pages Source 被设成了 "Deploy from a branch"。改为 **GitHub Actions**：

Settings → Pages → Source → GitHub Actions，然后重新 push 或在 Actions 页面手动 Run workflow。

## 修改主题样式后想还原

主题就在本仓库，直接用 git 回退对应文件即可：

```bash
git log --oneline -- assets/css/pages.css   # 找到改动前的提交
git checkout <commit> -- assets/css/pages.css
```
