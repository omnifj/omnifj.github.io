# 写作指南

## 新建文章

在仓库根目录执行：

```bash
hugo new posts/my-post.md
```

文件会创建在 `content/posts/my-post.md`，并自动套用 `archetypes/default.md` 模板。

URL 由文件路径决定：`content/posts/my-post.md` → `https://omnifj.github.io/posts/my-post/`

## Frontmatter 配置

文章顶部的元数据，完整示例：

```markdown
---
title: "文章标题"            # 必填
date: 2026-10-02           # 发布日期
draft: false               # true 时线上不发布（本地 -D 可见）
tags: ["Hugo", "教程"]      # 标签，可多个
categories: ["技术"]        # 分类，通常一个，显示在文章行和头部
keywords: ["关键词"]        # 可选，SEO 用（meta keywords / JSON-LD）
description: "文章摘要"      # 可选，列表页、文章页导语和 SEO 使用
summary: "列表摘要"          # 可选，description 为空时作为兜底
featured: true             # 可选，标记后进入首页「值得先读」
---
```

**重要**：`hugo new` 生成的文章默认 `draft: true`，发布前必须改为 `false`，否则线上不显示。

## 标签与分类

- 直接在 frontmatter 的 `tags` / `categories` 数组中填写即可，无需预先创建
- Hugo 自动生成聚合页：
  - 全部标签：`/tags/`，单个标签：`/tags/hugo/`
  - 全部分类：`/categories/`，单个分类：`/categories/技术/`
- 分类总览页同时作为「主题索引」，首页主题条和文章行都取第一个分类
- 建议标签用英文或简短中文，保持全站统一，避免同义词分散（如 hugo / Hugo 混用）

````markdown
## 目录（TOC）

无需配置。文章包含标题层级时自动生成，宽屏下固定在页面右侧，窄屏自动隐藏。

## 图片

图片放 `static/images/pic.png`，文中引用：

![描述](/images/pic.png)
````

## 本地预览

```bash
hugo server -D
```

浏览器打开 http://localhost:1313/ ，保存文件后自动刷新。`-D` 表示包含草稿。
